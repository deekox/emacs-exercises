===== important elisp info =====


There are two ways of variable scoping/binding:
1. dynamic (default)
(setq x 0)
(defun getx () x)
(setq x 1)
(let ((x 2))
  (message "the x is %d" (getx)))    => "the x is 2"

this is because 'x' in getx is searched on the stack and the closest 'x' on the stack is the one from let statement

2. lexical/static (turned on when ;;; -*- lexical-binding: t -*- is at the top of buffer
;;; -*- lexical-binding: t -*-
(setq x 0)
(defun getx () x)
(setq x 1)
(let ((x 2))
  (message "the x is %d" (getx)))    => "the x is 1"
  
this is because 'x' in getx is searched in global scope
note: (defvar variable_name) makes variable 'variable_name' dynamic even when in lexical-binding mode

===== HotKeys =====

C-u C-x C-e
    Evaluate expression and put the resutl on the buffer

Below NUM is called Prefix Argument
C-u NUM M-x forward-sentence
    Call NUM times an interactive f. forward-sentence
C-u NUM M-e
    Same as above (M-e is a hotkey for forward-sentence)
M-NUM M-x function-name
    Same as above but number is provided as keystroke
